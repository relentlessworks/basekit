basekit

Agentic-first base encoding & decoding service

Go Single Binary No Database Plain Text API MCP
View on GitHub Read the Docs

Principles

Agent IS the Interface

No UI, no SDK. The API is the product.

Plain Text by Default

One labeled, grepable line per record. JSON on demand.

Instructive Errors

Every 4xx includes a hint for self-correction.

Self-Documenting

GET /help returns a one-page operating manual.

Single Binary

Go, CGO_ENABLED=0, zero dependencies.

Zero Config

Runs out of the box. Config via flags or env.

Quick Start

# Build
make build

# Run
./basekit

# Encode
curl -X POST 'http://localhost:7700/encode?encoding=base64&data=hello'
# encoding=base64 input=hello output=aGVsbG8=

# Decode
curl -X POST 'http://localhost:7700/decode?encoding=base64&data=aGVsbG8='
# encoding=base64 input=aGVsbG8= output=hello

# Convert
curl -X POST 'http://localhost:7700/convert?from=hex&to=base64&data=68656c6c6f'
# from=hex to=base64 input=68656c6c6f output=aGVsbG8=

# Detect
curl -X POST 'http://localhost:7700/detect?data=aGVsbG8='
# encoding=base64
